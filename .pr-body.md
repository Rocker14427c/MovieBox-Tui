## Summary

Adds a full native Android port of MovieBox-Tui and fixes the MovieBox streaming that currently only returns a site trailer.

## What's included

**Native Android app (`android/`)**
- Compose UI: Home (hero + rails), Search, Detail (streams + seasons + favorites), in-app ExoPlayer, Live TV (M3U), Library (continue-watching + favorites).
- Single APK, no Termux/terminal setup.

**Streaming fix (both TUI + Android)**
- The MovieBox mobile `play-info` endpoint only returns a site trailer. Real links now resolve from:
  1. `resourceDetectors[].resolutionList[]` (movies) — signed CDN MP4s
  2. H5 web play endpoint `/wefeed-h5-bff/web/subject/play` (series) — needs the `detailUrl` slug as Referer
  3. Legacy `play-info`/`resource` fallback
- Deprecation/trailer clip is filtered; per-mirror User-Agent/Referer headers are applied to the CDNs.

**Build**
- Gradle wrapper + `build.sh` one-shot script.
- GitHub Actions workflow `.github/workflows/android-build.yml` that builds the debug APK and uploads it as an artifact.

## Checks
- The new **Android Build** workflow assembles the debug APK and uploads `app-debug.apk`.
- Existing Rust CI (`cargo check`, `clippy`) validates the backported TUI stream fix.
